# API Contract Guardian

Use for cross-application API contract drift and architecture-conformance analysis. Trace changed endpoints and contracts across providers, consumers, adapters, and tests; compare observed dependencies with the declared architecture; and report conformance with evidence and coverage limits. Keep implementation ownership with the code-change workflow.
